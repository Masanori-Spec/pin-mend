何を保証し、何を保証しないか
入力した制約の範囲で、変更する信号数が最小の割り当てを厳密に探索します。同数なら信号 ID 順でピン番号が小さい結果を選びます。配線長や作業時間は最適化しません。LED PWM の周波数は保存しません。任意のスケッチ解析・書き換え、実機への転送、電気的安全性・消費電力・ジッタの保証は対象外です。実機は未検証です。
